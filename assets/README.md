# Profile artwork

The headers, terminal, stack diagram, footer, and nine project illustrations are original, hand-written animated SVG. They use only CSS keyframes and SMIL, with no scripts, fonts, or external requests, so they animate inside GitHub's image proxy. CSS-driven motion respects `prefers-reduced-motion`.

Each project card has its own palette. Illustrations are conceptual diagrams, not screenshots or measured product data; amounts, messages, and chart values are placeholders.

Technology badges use locally bundled [Devicon](https://github.com/devicons/devicon) logos from commit `7330accdbc47e2dc0c19789a48533c4a3c50fe58`. The badge frames and labels are original; the logos retain their upstream colors and shapes. Devicon's MIT license is included in [stack/DEVICON-LICENSE.txt](stack/DEVICON-LICENSE.txt). Brand names and logos belong to their respective owners.

The five applied-AI badges use original line icons for concepts without a shared brand logo. All artwork includes accessible labels, and the README provides image alt text.
